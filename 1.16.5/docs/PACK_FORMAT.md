# Формат пака анимаций Pack Animation

Пак анимаций — это папка с тремя файлами: `idle.json`, `walk.json`, `run.json`.
Формат файлов — это подмножество формата анимаций GeckoLib/Bedrock, который
напрямую понимает библиотека **Player Animator** (KosmX), на которой построен
этот мод.

## Где лежат паки

* **Встроенные паки** (Ниндзя/Зомби/Робот) зашиты внутрь мода, их редактировать
  нельзя — это просто готовые примеры того, как это работает "из коробки".
* **Ваши паки** живут в обычном ресурс-паке, который мод сам создаёт и держит
  включённым:

  ```
  <папка игры>/resourcepacks/PackAnimation_CustomPacks/
  ├── pack.mcmeta
  ├── README.txt
  └── assets/
      ├── example_pack/                <- готовый пример для копирования
      │   ├── packanimation_meta.json
      │   └── player_animation/
      │       ├── idle.json
      │       ├── walk.json
      │       └── run.json
      └── my_cool_pack/                <- ваш пак
          ├── packanimation_meta.json  (необязательно)
          └── player_animation/
              ├── idle.json
              ├── walk.json
              └── run.json
  ```

  Имя папки внутри `assets/` (например `my_cool_pack`) — это ваш **pack id**.
  Разрешены только строчные латинские буквы, цифры, `_` и `-` (обычные правила
  Minecraft namespace).

* `packanimation_meta.json` — необязательный файл с отображаемым именем и
  автором:

  ```json
  {
    "name": "Мой крутой пак",
    "author": "Ваш ник"
  }
  ```

После добавления/изменения пака: в игре откройте меню Pack Animation (клавиша
**P** по умолчанию) и нажмите **"Обновить список паков"**, либо просто
перезайдите в мир.

## Формат idle.json / walk.json / run.json

```json
{
  "format_version": "1.8.0",
  "animations": {
    "idle": {
      "loop": true,
      "animation_length": 2.0,
      "bones": {
        "head":      { "rotation": { "0.0": [0, 0, 0], "1.0": [0, 15, 0], "2.0": [0, 0, 0] } },
        "torso":     { "rotation": { "0.0": [0, 0, 0] } },
        "right_arm": { "rotation": { "0.0": [0, 0, 0] } },
        "left_arm":  { "rotation": { "0.0": [0, 0, 0] } },
        "right_leg": { "rotation": { "0.0": [0, 0, 0] } },
        "left_leg":  { "rotation": { "0.0": [0, 0, 0] } },
        "body":      { "position": { "0.0": [0, 0, 0] } }
      }
    }
  }
}
```

> ### ⚠️ Самое важное правило
> Ключ внутри `"animations"` — это **не** произвольное название. Player Animator
> регистрирует анимацию в реестре под именем `<папка_пака>:<этот ключ>`, а имя
> файла при этом вообще не используется. Поэтому ключ обязан быть **ровно**
> `idle`, `walk` или `run` (строчными буквами):
>
> ```json
> "animations": { "idle": { ... } }     ✅ мод найдёт
> "animations": { "animation.my.idle": { ... } }   ❌ мод не найдёт
> ```
>
> Если ошибиться — пак будет виден в меню, но подсветится красным с надписью
> «Анимации не найдены», а анимации останутся ванильными.

* Каждый файл должен содержать ровно **одну** анимацию внутри `"animations"`,
  и её ключ — это `idle`, `walk` или `run` (см. правило выше).
* `"loop": true` — анимация зациклена (обязательно для idle/walk/run).
* `"animation_length"` — длина в **секундах**.
* `"bones"` — кости персонажа. Доступные имена (снейк_кейс или camelCase —
  оба варианта работают):

  | Кость          | Что это                                   |
  |----------------|--------------------------------------------|
  | `head`         | голова                                     |
  | `torso`        | торс/тело                                  |
  | `right_arm`    | правая рука                                |
  | `left_arm`     | левая рука                                 |
  | `right_leg`    | правая нога                                |
  | `left_leg`     | левая нога                                 |
  | `body`         | смещение/поворот всего игрока целиком      |

* У каждой кости можно задать `"rotation"` (поворот, **в градусах**, порядок
  `[x, y, z]`) и/или `"position"` (смещение в единицах модели: 16 единиц = 1 блок,
  то есть как обычные пиксели модели игрока).
* Ключи внутри `"rotation"`/`"position"` — время в секундах ("0.0", "1.0", ...),
  между ключевыми кадрами используется линейная интерполяция.
* Кость, которую вы не трогаете в конкретной анимации, можно вообще не
  указывать — она останется как в ванильной анимации.

Простой рабочий пример лежит в `assets/example_pack/` внутри
`PackAnimation_CustomPacks` (мод создаёт его сам при первом запуске) — удобнее
всего скопировать его папку и менять цифры.

## Как сделать анимацию в Blender

В комплекте с модом идёт папка `blender_addon/` — аддон для Blender,
экспортирующий выделенное действие (Action) в описанный выше JSON.

Кратко (полная инструкция — `blender_addon/README.md`):

1. Установите аддон: `Edit > Preferences > Add-ons > Install...` и укажите
   файл `blender_addon/io_export_packanimation.py`, затем включите галочку
   у появившегося аддона.
2. Создайте/используйте арматуру (rig) с костями, названными **точно** как в
   таблице выше: `head`, `torso`, `right_arm`, `left_arm`, `right_leg`,
   `left_leg`, `body` (регистр не важен, `RightArm`/`right_arm`/`rightArm` —
   всё это распознаётся).
3. Анимируйте позу арматуры как обычно (Pose Mode, keyframes на Rotation, и
   при желании Location для кости `body`).
4. Выставьте частоту кадров сцены — рекомендуется **20 fps** (как в
   Minecraft), но аддон корректно работает с любым fps сцены.
5. `File > Export > Pack Animation (.json)`, выберите, зациклена ли анимация
   (Loop), и сохраните как `idle.json` / `walk.json` / `run.json` прямо в
   папку вашего пака.

Аддон переводит повороты костей в градусы и время кадров — в секунды
относительно реального fps сцены, так что результат не зависит от того, на
каком fps вы анимировали.
