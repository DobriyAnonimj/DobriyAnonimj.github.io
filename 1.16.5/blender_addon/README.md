# Blender-аддон Pack Animation

Экспортирует анимацию (Action) арматуры прямо в формат, который понимает мод
**Pack Animation**. Полное описание самого формата — в `docs/PACK_FORMAT.md`.

## Установка

1. Blender → `Edit > Preferences > Add-ons > Install...`
2. Выберите файл `io_export_packanimation.py` из этой папки.
3. Включите галочку у появившегося аддона **"Pack Animation (.json) exporter"**.
4. Теперь в `File > Export` появится пункт **"Pack Animation (.json)"**.

## Требования к арматуре (rig)

Кости должны называться так, чтобы их можно было распознать (регистр и
`_`/`-` не важны — `right_arm`, `rightArm`, `RightArm` — всё сработает):

* `head` — голова
* `torso` (или `chest`) — торс
* `right_arm`, `left_arm` — руки
* `right_leg`, `left_leg` — ноги
* `body` (или `root`) — кость смещения всего игрока целиком (нужна редко,
  например для приседания ниндзя или прыжков робота)

Лишние кости в арматуре (пальцы, доп. кости для риггинга и т.д.) аддон просто
проигнорирует — они не попадут в экспорт.

## Как анимировать

1. Выделите арматуру, зайдите в Pose Mode.
2. Создайте (или выберите) Action в Dope Sheet / Action Editor.
3. Ставьте ключевые кадры на **Rotation** нужных костей (для `body` — ещё и на
   **Location**, если нужно сместить игрока целиком, например присесть).
4. Настройте длину анимации через `Output Properties > Frame Start/End`.
5. Для зацикленных анимаций (idle/walk/run это всегда так) следите, чтобы поза
   на последнем кадре плавно продолжала первый.

## Экспорт

1. Выделите арматуру → `File > Export > Pack Animation (.json)`.
2. В диалоге экспорта настройте:
   * **Animation name** — просто для внутренней метки в json, не влияет на
     работу мода.
   * **Loop** — включено для idle/walk/run.
   * **Position scale** — во сколько раз умножать Location кости `body`
     (по умолчанию 16, так как в Minecraft 16 единиц модели = 1 блок).
   * **Skip unanimated bones** — не писать в файл кости, которые вообще не
     двигаются (уменьшает размер файла).
   * **Swap Y/Z rotation axis** — см. ниже.
3. Сохраните файл с именем `idle.json`, `walk.json` или `run.json` прямо в
   папку вашего пака (`resourcepacks/PackAnimation_CustomPacks/assets/<ваш_пак>/player_animation/`).

## Про оси (Swap Y/Z rotation axis)

У Minecraft и Blender разное соглашение об осях, и то, как именно повороты
костей вашей арматуры лягут на оси Minecraft, зависит от того, как именно
собран/сориентирован ваш риг — единого правильного ответа "на все риги" нет.

Проверка за 30 секунд:
1. Сделайте тестовую анимацию — поверните **голову** на 45° только по одной
   оси (например, только "кивок" вперёд).
2. Экспортируйте, поставьте пак в игру и посмотрите, что произошло с головой.
3. Если голова наклонилась не в ту сторону (например, повернулась влево-вправо
   вместо кивка) — включите **Swap Y/Z rotation axis** и экспортируйте заново.

После того как вы подобрали правильное значение один раз для своего рига,
оно будет одинаковым для всех ваших анимаций этим ригом.
