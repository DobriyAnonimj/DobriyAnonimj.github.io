# Pack Animation — плагин для Bukkit / Spigot / Paper / Purpur

Fabric-мод физически нельзя поставить на Paper/Purpur — это разные платформы
(Bukkit API против внутренностей Minecraft). Но серверной части Pack Animation
почти нечего делать: она только запоминает, кто какой пак анимаций выбрал, и
пересылает это остальным игрокам. Ровно это и делает данный плагин.

**Анимации по-прежнему рисует клиент.** Каждому игроку нужны Fabric + Fabric
API + Player Animator + сам мод Pack Animation. Плагин на сервере нужен только
для того, чтобы игроки **видели паки друг друга** (как эмоции в Emotecraft).

## Сборка

```bash
cd bukkit-plugin
gradle build
```

Готовый `PackAnimation-Bukkit-1.0.0.jar` появится в `bukkit-plugin/build/libs/`.
Это независимая сборка — она никак не связана с Fabric-сборкой мода и не
требует Loom.

## Установка

Положите jar в папку `plugins/` вашего сервера и перезапустите его. Настраивать
нечего: ни конфига, ни команд, ни прав у плагина нет.

В консоли при запуске появится:

```
[PackAnimation] Pack Animation relay enabled. Players need the Pack Animation
client mod (Fabric) + Player Animator to see each other's animation packs.
```

## Как это работает

Обмен идёт по обычным plugin messaging каналам Bukkit — без NMS, без
ProtocolLib и без привязки к конкретной версии сервера, так что плагин не
ломается при обновлении Paper/Purpur.

| Канал | Направление | Что передаёт |
|-------|-------------|--------------|
| `packanimation:select_pack` | клиент → сервер | «я выбрал пак X» |
| `packanimation:sync_pack`   | сервер → клиенты | «у игроков A, B, C паки X, Y, Z» |

Формат байтов (big-endian, как у `DataOutputStream`):

```
select_pack:  short idLen, byte[idLen] utf8
sync_pack:    int count, count x (long msb, long lsb, short idLen, byte[idLen] utf8)
```

Тот же протокол реализован и в Fabric-версии серверной части
(`PackAnimationMod.java` в основном моде), поэтому клиент один и тот же и не
знает, на каком сервере он играет.

## Важно

* Ставить нужно **что-то одно**: либо этот плагин (Bukkit-семейство), либо
  сам мод на Fabric-сервер. Одновременно они не нужны и не могут работать —
  это разные платформы.
* Игроки **без** клиентского мода никак не пострадают: плагин ничего им не
  шлёт сверх канала, который они просто игнорируют, и видят обычные ванильные
  анимации.
* Плагин ничего не хранит на диске: список «кто какой пак выбрал» живёт в
  памяти, пока сервер запущен. Свой выбор клиент присылает заново при каждом
  заходе.
